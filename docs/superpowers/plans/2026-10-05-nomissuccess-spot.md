# nomissuccess-Spot „Nachtschicht“ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 2:20–2:40 commercial for nomissuccess (+2 s end card) in 16:9 and 9:16 at 60 fps. It is assembled in a fully editable DaVinci Resolve project „nomiss“. The 3D shots come from Blender, the kinetic type from Fusion, and voice, music and SFX are generated by code.

**Architecture:** One data contract drives everything. `script.json` (text) and `szenen/events.json` (visual beats anchored to spoken words) go into `audio/plan.py`, which writes `timeline.json` (absolute seconds/frames for scenes, VO lines, words, events, SFX cues). Blender shots, Fusion comps, music, SFX and the Resolve timeline builder all read `timeline.json`, so picture and sound stay in sync and everything re-times when the voice changes.

**Tech Stack:** Python 3.12 venv (uv) · numpy/scipy/soundfile/pyloudnorm · faster-whisper (local alignment) · Gemini TTS REST (`gemini-3.8-flash-lite-tts`, voice `de-de-techagent-6`) · Blender 5.2 (bpy, EEVEE, headless `blender -b`) · DaVinci Resolve Studio 21.1.1 scripting API (external Python: `RESOLVE_SCRIPT_API=/opt/resolve/Developer/Scripting`, `RESOLVE_SCRIPT_LIB=/opt/resolve/libs/Fusion/fusionscript.so`, `PYTHONPATH=$RESOLVE_SCRIPT_API/Modules`) · Fusion `.comp` files · ffmpeg (final H.264 from Resolve's ProRes master).

**Spec:** `brief/PROMPT.md` (approved by Anthony on 05.10.2026: „passt alles … mach fertig“; end card „made by nomissuccess“; „nomissuccess“ is passed to the voice literally, with no respelling).

3. **Loudness drift when one stem is re-rendered:** the mix must re-measure, not reuse a cached gain. Test: changing the SFX stem changes the master gain and the result is still −14 ± 0.5 LUFS.
4. **9:16 crop cutting off 3D content:** every Blender shot exposes a centre-square check. Test: render a 3-frame proxy and assert the alpha bounding box of key objects lies inside the centre 1080×1080 at anchor frames.
5. **Re-running the Resolve builder duplicates media or tracks:** the builder must be idempotent (delete or rebuild only its own timelines and bins). Test: run twice, then the media pool clip count and timeline item counts are unchanged.

### Task 1: Voice, alignment, timeline contract

**Files:** Create `script.json` (copy text v01–v23 verbatim from the brief, §3), `audio/gemeinsam.py`, `audio/stimme.py`, `audio/plan.py`, `scripts/fonts.sh`, `tests/test_plan.py`, `tests/test_stimme.py`, `pyproject.toml`. `szenen/events.json` is provided by the director.

**Interfaces:**
- Produces `assets/audio/vo/<id>.wav` (48 kHz mono, trimmed, 20 ms fades), `work/vo/ausrichtung.json`, and `timeline.json`:
```json
{"fps":60,"dauer_s":0.0,"dauer_f":0,
 "abspann":{"start_s":0.0,"ende_s":0.0},
 "szenen":[{"id":"s1_nacht","start_s":0.0,"ende_s":0.0,"start_f":0,"ende_f":0}],
 "vo":[{"id":"v01","szene":"s1_nacht","start_s":0.0,"ende_s":0.0,"datei":"assets/audio/vo/v01.wav",
        "woerter":[{"wort":"Drei","start_s":0.0,"ende_s":0.0}]}],
 "events":[{"id":"clock_roll","szene":"s1_nacht","t_s":0.0,"f":0,"sfx":"tick"}],
 "cues":[{"t_s":0.0,"art":"whoosh","szene":"s1_nacht","quelle":"event:clock_roll"}]}
```
- Timing rules in `plan.py`: scene 1 has 1.6 s pre-roll; 0.30 s between lines in a scene; 1.10 s between scenes; scene 8 holds 2.8 s after the last word; the end card lasts 2.0 s. Event time = anchored word start + `offset_s`.
- TTS: 3 requests (block A v01–v08, B v09–v15, C v16–v23), joined with paragraph breaks; one take each. A second take only for a block whose Whisper WER > 0.12 against the script. The split into lines comes from word alignment (difflib on normalised tokens). Style: `moderner Werbespot, klar, warm und selbstbewusst, zügiges natürliches Tempo`.

### Task 2: SFX, music, mix

**Files:** `audio/sfx.py`, `audio/musik.py`, `audio/mix.py`, `tests/test_mix.py`.
**Interfaces:** Consumes `timeline.json`. Produces `assets/audio/stems/{vo,musik,sfx_whoosh,sfx_hit,sfx_ui,sfx_uebergang,sfx_signatur,sfx_atmo}.wav` (48 kHz stereo, same length = `dauer_s`) and `out/mix_referenz.wav`. Mix gains are written to `work/mix/pegel.json`. The stems summed at unity gain must equal the reference mix (the Resolve tracks sit at 0 dB).
- SFX kinds: `whoosh, hit, tick, riser, downer, click, lock, paper, clatter, sting, shimmer, subdrop, rewind, swell`. All synthesized and deterministic (fixed seeds). Every cue is placed so that its transient lands on `t_s`; whooshes end on `t_s`. EQ: whooshes and atmo high-passed at 120 Hz and dipped −4 dB at 2–4 kHz while VO is active.
- Music: ~100 BPM in A minor, mapped to the night arc. s1: sub pulse plus the clock tick as hi-hat. s2–s3: build with plucks. s4: thin, low drone. s5–s6: drive. s7: lift. s8: warm major resolve. The last chord rings ≥ 3 s under the end card. Scene starts sit on bar lines where possible; events with `hit` get a percussive accent on the nearest 1/16 note within ±40 ms.
- Ducking: music is ≥ 15 dB below the VO's short-term level while words are spoken (sidechain from VO word intervals, 60 ms attack, 350 ms release). No limiter on the VO; the master has a true-peak safety ceiling −1 dBTP applied only above −1.5 dBTP.
- [ ] Tests: the mix is −14 ± 0.5 LUFS, ≤ −1 dBTP, and the duck is ≥ 15 dB on a fixture timeline; stems sum ≈ reference (max abs diff < 1e-3); phone test ≥ 45 %; deterministic output (same hash twice).
- [ ] Implement, test, commit.
